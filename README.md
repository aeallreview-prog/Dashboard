# seek n tique — แดชบอร์ดยอดขาย (local app)

แอปหน้าเดียวที่ดึงข้อมูลสดจาก Google Sheet มาแสดงเป็นแดชบอร์ด รันในเครื่องได้เลย ไม่ต้องมีเซิร์ฟเวอร์

## วิธีใช้งาน

1. **เปิดสิทธิ์การเข้าถึงชีต**: ไปที่ Google Sheet → ปุ่ม Share → เปลี่ยนเป็น **"Anyone with the link can view"**
   (จำเป็น เพราะแอปดึงข้อมูลจากเบราว์เซอร์ของคุณโดยตรง ไม่ผ่านเซิร์ฟเวอร์)
2. เปิดไฟล์ `index.html` ด้วยเบราว์เซอร์ (ดับเบิลคลิกได้เลย หรือรันเซิร์ฟเวอร์เล็กๆ เช่น
   `npx serve .` หรือ `python3 -m http.server` แล้วเข้า `http://localhost:8000`)
3. กดปุ่ม **"ตั้งค่า"** มุมขวาบน ใส่:
   - **Google Sheet ID** (ค่าเริ่มต้นตั้งไว้ให้แล้วจาก URL ที่ให้มา)
   - **ชื่อแท็บ** ถ้ามีหลายแท็บในไฟล์เดียวกัน (เว้นว่างได้ถ้าใช้แท็บแรก)
   - **คอลัมน์สถานะสินค้า** — ค่าเริ่มต้นเป็น "ตรวจจับอัตโนมัติ" (แอปจะหาให้เองว่าคอลัมน์ไหนมีค่าตรงกับ 4 สถานะ)
     ถ้าตรวจจับผิดคอลัมน์ เลือกคอลัมน์ที่ถูกต้องเองได้
   - ความถี่รีเฟรช (ค่าเริ่มต้น 30 วินาที)
4. กด "บันทึก & โหลดใหม่" — ค่าที่ตั้งจะถูกจำไว้ในเบราว์เซอร์เครื่องนี้ (localStorage)

## แนวโน้มรายได้ กำไร และรายจ่าย (กราฟเส้น)

กราฟนี้ต้องมีการตั้งค่าเพิ่ม 1 ครั้ง เพราะ Google Sheet เองไม่มี "ประวัติ" ของค่า U2 (รายรับ), V2 (กำไร) และ T2 (รายจ่าย) ให้ดึงย้อนหลังได้
ต้องให้ Sheet บันทึกค่าไว้เองทุกสัปดาห์ก่อน วิธีตั้งค่า:

1. เปิด Google Sheet → **Extensions → Apps Script**
2. สร้างไฟล์ logger หรือแทนที่เฉพาะโค้ด logger เดิมด้วยไฟล์ `apps-script-revenue-logger.gs` ที่แนบมาด้วย แล้วกดบันทึก (Ctrl+S) — อย่าลบไฟล์ Write API หรือสคริปต์อื่น หากเคยเปลี่ยนชื่อแท็บข้อมูลหลักไว้ ให้คงชื่อแท็บนั้นใน `sourceSheet`
3. คลิกไอคอนนาฬิกา (⏰) ด้านซ้าย → **Add Trigger** → เลือกฟังก์ชัน `logWeeklyRevenue` →
   Event source: **Time-driven** → Type: **Week timer** → Day: **Monday** → Time: **Midnight to 1am** → Save
4. ครั้งแรกจะขอ authorize สิทธิ์เข้าถึง Sheet — กด Allow ตามขั้นตอน
5. สคริปต์จะสร้างแท็บใหม่ชื่อ **RevenueHistory** อัตโนมัติ แล้วบันทึกค่าทุกวันจันทร์: A = Date, B = Revenue (U2), C = Profit (V2), D = Expense (T2)

กราฟจะเริ่มมีข้อมูลตั้งแต่ trigger รันหลังจากตั้งค่าเสร็จ — **ไม่มีข้อมูลย้อนหลังก่อนหน้านี้ให้ดึงได้** หากต้องการเก็บจุดแรกทันที ให้เลือกฟังก์ชัน `logWeeklyRevenue` แล้วกด Run เพื่อบันทึกยอดจริงปัจจุบัน กราฟจะขึ้นเส้นเมื่อมีอย่างน้อย 2 จุดในช่วงที่เลือก

**อัปเดตจาก logger เดิม:** แทนที่เฉพาะโค้ด logger แล้วกดบันทึกได้เลย ใช้ trigger เดิมของ `logWeeklyRevenue` ต่อได้ ไม่ต้องสร้างซ้ำหรือ Deploy Web App ใหม่ สคริปต์เพิ่มหัวคอลัมน์ D เป็น Expense และคงประวัติเดิมไว้ ช่องรายจ่ายในแถวเก่าที่ไม่เคยบันทึกจะยังว่างและไม่ถูกนับเป็นศูนย์ หากคอลัมน์ D มีข้อมูลอื่น สคริปต์จะหยุดให้ตรวจสอบก่อน ไม่เขียนทับ

กราฟรายจ่ายใช้สีแดงและยอด T2 ที่บันทึกไว้โดยตรง ไม่คำนวณจากรายรับลบกำไร กด "วัน / สัปดาห์ / เดือน / ปี" หรือเลือกวันที่เพื่อเปลี่ยนช่วงพร้อมกันทั้ง 3 กราฟ สัปดาห์นับจันทร์–อาทิตย์ และแกนตั้งปรับตามค่าที่มีในช่วงที่แสดง

## แก้ไข/เพิ่มสินค้า และแก้ไขรายรับ-รายจ่ายร้าน (เขียนข้อมูลกลับเข้า Sheet)

ฟอร์มรายจ่ายแสดงชื่อ **เดินทาง (Q2)**, **อุปกรณ์ (R2)** และ **ads (S2)** พร้อมยอดปัจจุบันจากชีต ช่องกรอกเป็นยอดที่จะบวกเพิ่ม เช่น ปัจจุบัน 100 บาท กรอก 50 บาท จะบันทึกยอดรวม 150 บาท มีตัวอย่างยอดหลังเพิ่มก่อนบันทึก ช่องว่างหรือ 0 คงยอดเดิม รองรับสตางค์ 2 ตำแหน่ง ระบบอ่านยอดอีกครั้งก่อนบันทึกผ่าน API เดิม จึงไม่ต้อง Deploy Apps Script ใหม่ การเพิ่มยอดยังเป็นการอ่านแล้วเขียนยอดรวม หากมีหลายคนแก้รายการเดียวกันพร้อมกันอาจทับกันได้

ฟีเจอร์นี้ต้องตั้งค่าเพิ่ม 1 ครั้ง เพราะการเขียนข้อมูลกลับเข้า Google Sheet ต้องผ่าน Apps Script
(การอ่านข้อมูลแบบปกติไม่ต้องใช้ แต่การ**เขียน**ต้องมี "ทางเขียน" ที่ตั้งไว้ก่อน)

**คอลัมน์ที่แก้ไขผ่านเว็บได้:** รูปภาพ (P), รายละเอียด (C), ต้นทุนของ (E), ราคาขาย (F), ขายแล้ว (H),
ค่าส่งจากลูกค้า (I), ค่าส่งจริง (J), หมายเหตุ (K), สถานะ (O)

**คอลัมน์ที่เป็นสูตร จะไม่ถูกแก้ไขจากเว็บเด็ดขาด:** No. (A) = `ROW()-2`, กำไรของ (G) = `F-E`,
กำไรของ (L) = `H+I-E-J` — ตอนเพิ่มสินค้าใหม่ ระบบจะเขียนสูตรเหล่านี้ให้เองในแถวใหม่โดยอัตโนมัติ

### วิธีตั้งค่า

1. เปิด Google Sheet → **Extensions → Apps Script** (หน้าเดียวกับที่ตั้ง Apps Script บันทึกรายได้ไว้ก่อนหน้านี้ได้เลย)
2. คลิก **+** ข้าง Files เพื่อสร้างไฟล์สคริปต์ใหม่ ตั้งชื่อว่า `write-api` แล้ววางโค้ดจากไฟล์
   `apps-script-write-api.gs` ที่แนบมาด้วย จากนั้นกดบันทึก (Ctrl+S)
3. กด **Deploy → New deployment**
   - Select type: **Web app**
   - Execute as: **Me**
   - Who has access: **Anyone**
   - กด Deploy → อาจต้อง Authorize สิทธิ์อีกครั้ง
4. คัดลอก **Web app URL** ที่ได้ (จะขึ้นต้นด้วย `https://script.google.com/macros/s/.../exec`)
5. กลับมาที่แดชบอร์ด → กด **"ตั้งค่า"** → วาง URL ลงในช่อง **"Web App URL"** → บันทึก

เสร็จแล้วปุ่ม "แก้ไข" (ในการ์ดค้นหา/ตารางสินค้า), "+ เพิ่มสินค้าใหม่", และ "แก้ไขรายรับ-รายจ่ายร้าน" (หน้า Dashboard) จะใช้งานได้

**ความปลอดภัย:** คำขอเขียนข้อมูลทุกครั้งจะแนบรหัสผ่านเดียวกับหน้า login (`snt`) ไปด้วย ถ้าอยากเปลี่ยนรหัสลับนี้
แก้ตัวแปร `API_SECRET` ในไฟล์ `apps-script-write-api.gs` ได้เลย (ควรตั้งให้ตรงกับ `LOGIN_PASSWORD` ใน `app.js` เสมอ)

## ข้อมูลที่แสดง

- **รายรับ** ← ช่อง `U2`
- **รายจ่าย** ← ช่อง `T2`
- **กำไร** ← ช่อง `V2`
- **สถานะสินค้า** ← นับจำนวนทุกแถวในคอลัมน์ที่ตรวจพบ (หรือระบุเอง) แบ่งเป็น 4 กลุ่ม:
  - ยังไม่ได้ลงขาย — สีเทา
  - ส่งแล้ว — สีเขียว
  - ลงขายแล้ว — สีน้ำเงิน
  - ขายได้บางส่วน — สีเหลือง

ตารางข้อมูลดิบไม่ถูกแสดงในแดชบอร์ด (ตามที่ขอ) — มีแค่ตัวเลขสรุปและกราฟวงกลมสัดส่วนสถานะ

## ไฟล์ในโปรเจกต์

- `index.html` — โครงหน้าเว็บ
- `style.css` — ธีมสี/ดีไซน์ (ใช้สีจากโลโก้ seek n tique: น้ำเงิน `#1a63a8`, ส้ม `#f15e22`, ครีม `#f0f3bc`)
- `app.js` — โค้ดดึงข้อมูลจาก Google Sheets แบบเรียลไทม์ (Google Visualization API, ฝั่ง client)
- `logo.png` — โลโก้เต็ม ไม่ถูก crop

## แนวโน้มผู้ติดตาม Instagram

กรอกยอดผู้ติดตามเองในหน้า Dashboard โดยเปิด IG ดูยอดปัจจุบันแล้วกรอก **ยอดทั้งหมด** ไม่ใช่จำนวนที่เพิ่ม ระบบไม่เข้า IG อัตโนมัติและไม่ต้องส่งประวัติขึ้น GitHub ทุกครั้งที่กรอก

- บันทึกผ่าน Apps Script ลงแท็บ `FollowerHistory` ใน Google Sheet เดิม แยกจากสินค้าและรายรับรายจ่าย ทุกอุปกรณ์อ่านประวัติเดียวกัน
- วันที่และเวลาบันทึกมาจากเซิร์ฟเวอร์ ตามเขตเวลา Asia/Bangkok กรอกซ้ำในวันเดียวกันจะอัปเดตแถวเดิม ไม่เพิ่มจุดซ้ำ ใช้ยอดที่บันทึกล่าสุด
- ถ้ายังไม่มีรายการที่กรอกเองในสัปดาห์ปัจจุบัน (จันทร์–อาทิตย์ เวลาไทย) จะแสดงคำเตือนในหน้าแดชบอร์ด และซ่อนหลังเซิร์ฟเวอร์ยืนยันบันทึกสำเร็จ เริ่มรอบใหม่วันจันทร์ 00:00 น. ใช้รอบเดียวกับกราฟรายได้ กำไร และผู้ติดตาม ไม่ใช่ push notification และไม่แจ้งเตือนขณะปิดเว็บ
- โหลดประวัติเมื่อเปิดหน้า กด “โหลดข้อมูลล่าสุด” หรือกลับมายังแท็บ ตรวจการเปลี่ยนสัปดาห์ทุกนาทีขณะเปิดหน้า ถ้าเชื่อมต่อไม่ได้จะแสดงข้อผิดพลาดและไม่สรุปว่าสัปดาห์นี้ยังไม่ได้กรอก
- คงประวัติเดิมใน `followers-history.js` ไว้ กราฟรวมกับข้อมูลที่กรอกเอง โดยใช้ข้อมูลที่กรอกเองเมื่อวันที่ซ้ำ ไม่มีการสร้างข้อมูลย้อนหลังหรือเติมวันที่ขาด
- กราฟเลือกวัน สัปดาห์ เดือน ปี หรือช่วงวันที่ได้ แสดง 8 จุดล่าสุด หรือสูงสุด 40 จุดเมื่อระบุวันที่ หลังบันทึกจะเปลี่ยนเป็นกราฟวันและล้างตัวกรองวันที่ให้เห็นยอดที่เพิ่งกรอก
- กราฟเส้นรายได้ กำไร และผู้ติดตามปรับแกนตั้งอัตโนมัติจากค่าต่ำสุด–สูงสุดของจุดข้อมูลที่แสดง เช่น 300–350 จะแสดงแกนตั้ง 300–350 ไม่เริ่มที่ศูนย์และไม่ล็อกช่วง 300–500 หากทุกจุดเท่ากันหรือมีจุดเดียว จะเผื่อช่วงเล็กน้อยเพื่อให้เห็นเส้นหรือจุดชัดเจน

### เปิดใช้งานแบบกรอกเอง (ทำครั้งเดียว)

1. ใน Apps Script ของ Google Sheet เดิม แทนที่โค้ด write API ด้วย `apps-script-write-api.gs` เวอร์ชันนี้ เก็บ revenue logger เดิมไว้
2. ไปที่ Deploy → Manage deployments → แก้ไข deployment เดิม → Version: New version → Deploy เพื่อคง Web App URL เดิม หากใช้ URL ใหม่ให้เปลี่ยน Web App URL ในการตั้งค่าแดชบอร์ดด้วย
3. เผยแพร่ไฟล์หน้าเว็บที่เปลี่ยนบน Vercel: `index.html`, `style.css`, `followers-chart.js`, `seek-n-tique-dashboard.html` และคง `followers-history.js` ที่มีประวัติเดิมไว้
4. เปิดเว็บแล้วกด “โหลดข้อมูลล่าสุด” ช่องบันทึกจะเปิดใช้งานเมื่อ API รุ่นใหม่ตอบสำเร็จ แท็บ FollowerHistory จะถูกสร้างเมื่อบันทึกครั้งแรก

หากยังไม่ได้อัปเดต Apps Script จะอ่านประวัติเก่าได้เท่านั้นและปิดปุ่มบันทึกพร้อมแจ้งเหตุ งานอ่าน IG รายวันใน Codex ถูกพักเมื่อเปลี่ยนมาใช้วิธีนี้ ไม่ต้องตั้งงาน GitHub/Vercel รายวัน

## หมายเหตุ

ถ้าตัวเลขไม่ขึ้นหรือขึ้น "โหลดข้อมูลไม่สำเร็จ" ให้เช็ก 2 อย่างก่อน:
1. Sheet ตั้งเป็น "Anyone with the link can view" หรือยัง
2. Sheet ID / ชื่อแท็บ ในหน้าตั้งค่าตรงกับไฟล์จริงหรือไม่
